### 1.1. Trụ cột 1: Bảo hộ Thương hiệu & Triệt tiêu Hijacker (Brand Protection)
* **Đăng ký Amazon Brand Registry:** Hoàn tất hồ sơ đăng ký nhãn hiệu với USPTO (Cơ quan Sáng chế & Nhãn hiệu Hoa Kỳ) và kích hoạt Brand Registry 2.0 trên Amazon.
* **Kích hoạt Transparency Program:** Dán tem mã 2D Transparency chống hàng giả lên từng bao bì trước khi rời xưởng Việt Nam, ngăn chặn 100% tình trạng gian thương gắn chung ASIN (Hijacker / Piggybacking).
* **Báo cáo vi phạm sở hữu trí tuệ (Report a Violation - RAV):** Tự động quét và phát hiện các seller bán phá giá hoặc dùng trái phép hình ảnh bản quyền của nhà xưởng VN để gửi trát bản quyền gỡ bỏ trong 24 giờ.

  * 5 Bullet Points nhấn mạnh vấn đề & giải pháp thay vì chỉ liệt kê tính năng.

* **Thiết kế Premium A+ Content (EBC) & Brand Story:** Kể câu chuyện di sản nông sản Việt Nam (Hạt cacao hữu cơ Bến Tre, Nhang trầm hương tự nhiên Nghệ An) bằng hình ảnh thực tế chất lượng cao, bảng so sánh tính năng (Comparison Charts) để nâng tỷ lệ chuyển đổi (Unit Session Percentage) lên $\ge 18\%$.
* **Xây dựng Amazon Brand Storefront:** Thiết kế gian hàng chính hãng đa trang với video trải nghiệm sản phẩm, tối ưu cho giao diện Mobile (chiếm 72% lượng truy cập mua sắm tại Mỹ).

### 2.1. Phân quyền Đa tầng & Cô lập Dữ liệu Nhà xưởng (Multi-Tenant Isolation via RLS)
* **Nhà xưởng Việt Nam (Clients - Vinacacao, Thảo Mộc An An...):**
  * Đăng nhập chỉ xem được duy nhất dữ liệu doanh thu, lợi nhuận ròng, tồn kho và chi phí quảng cáo của chính thương hiệu mình.
  * Được bảo vệ ở cấp độ Database thông qua **PostgreSQL Row Level Security (RLS)**:
    ```sql
    CREATE POLICY "client_data_isolation" ON orders
    FOR SELECT USING (
      auth.jwt() ->> 'role' = 'super_admin' OR 
      client_id = (SELECT client_id FROM public.users WHERE id = auth.uid())
    );
    ```
* **Nhân sự Vexim Internal (Admins, Logistics, PPC, Brand CX):**
  * Xem toàn quyền hoặc theo phân hệ chức năng (RBAC) để phục vụ công tác tối ưu hóa và hỗ trợ khách hàng.

### 2.4. Khả năng Chịu tải & Giám sát Hệ thống (Reliability, Scalability & SRE)
1. **Zero-Data Loss Architecture:** Kiến trúc bộ nhớ đệm 3 tầng (HTML5 LocalStorage Hydration + Redis Memory Store + PostgreSQL Master-Slave DB) đảm bảo người dùng F5 hoặc mất mạng đột ngột không bị mất dữ liệu đang nhập dở.
2. **Rate Limit Handling (Exponential Backoff):** Amazon SP-API có giới hạn gọi API (Throttling Limits). Hệ thống tích hợp thuật toán Leaky Bucket tự động điều phối hàng đợi yêu cầu, tránh bị Amazon khóa API Key.
3. **Giám sát & Cảnh báo Sức khỏe 24/7:** Tích hợp Sentry (báo lỗi Exception) và UptimeRobot giám sát API Gateway, đảm bảo tỷ lệ Uptime $\ge 99.95\%$.
