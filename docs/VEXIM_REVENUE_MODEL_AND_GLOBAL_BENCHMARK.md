## 4. VÍ DỤ MINH HỌA DÒNG TIỀN THỰC TẾ (CASE STUDY VINACACAO)

Giả sử nhãn hàng **Vinacacao** vận hành qua hệ thống Vexim sau 6 tháng đạt mốc doanh thu **\$80,000 USD / tháng**:

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 BẢNG PHÂN TÍCH DOANH THU VEXIM TỪ 1 KHÁCH HÀNG              │
├────────────────────────────────────────────────┬────────────────────────────┤
│ HẠNG MỤC THU PHÍ                               │ SỐ TIỀN VEXIM THU VỀ (USD) │
├────────────────────────────────────────────────┼────────────────────────────┤
│ 1. Phí Quản trị nền tảng cố định hàng tháng    │ $1,200 / tháng             │
│ 2. Hoa hồng 6% trên Doanh số ($80,000 x 6%)    │ $4,800 / tháng             │
│ 3. Chênh lệch dịch vụ Kho 3PL California       │ $450 / tháng               │
│ 4. Phí đòi bồi thường FBA (Đòi được $1,500)    │ $225 (15% của $1,500)      │
├────────────────────────────────────────────────┼────────────────────────────┤
│ 💎 TỔNG DOANH THU VEXIM THU ĐƯỢC TỪ VINACACAO  │ $6,675 USD / THÁNG         │
│    (Tương đương ~ 168 Triệu VNĐ / Tháng)       │                            │
└────────────────────────────────────────────────┴────────────────────────────┘
```

* **Về phía Nhà Xưởng Vinacacao:** Rất vui vẻ thanh toán \$6,675 vì họ thu về \$80,000 doanh số xuất khẩu và lợi nhuận ròng sạch \$28,000 USD/tháng mà không cần phải tự xây dựng bộ máy chuyên viên tại Mỹ.
* **Về phía Vexim:** Có nguồn thu lớn gấp 5.5 lần so với việc chỉ thu \$1,200 cố định!
